GitHub

the-brAIn-lab. The lab's own repositories, including SuperEEG and the code behind our research projects.

Python

Timecorr Toolbox. Estimate dynamic high-order correlations in multivariate timeseries data.

SuperEEG Toolbox. Infer whole-brain activity from a smallish number of ECoG electrodes.

HyperTools. Visualize and manipulate high-dimensional data.

AEPsych. A framework focused on human-in-the-loop training of human psychophysics.

JavaScript

Observable. A software platform that uses JavaScript and coding cell structures to create powerful visualizations.
